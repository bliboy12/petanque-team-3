Install instructions
-----------------

The steps below need to be executed only once:

Download and install 'MySQL Server 8.4 (LTS)' from https://dev.mysql.com/downloads/mysql/
(install on port 3306 with user=root, password=root)
or make sure you have access to a MySQL server.

Open PowerShell and run:

    winget install git.git
    winget install Microsoft.DotNet.SDK.8
    winget install node.js
    exit

Open PowerShell again and run:
(after the installation of Git, DotNet SDK and NodeJS
 it is mandatory to exit PowerShell and start it again
 in order to activate some environment variables)

    # make a clone of the code
    mkdir scr
    cd src
    git clone https://github.com/goedertw/petanque.git

    # allow running PowerShell scripts
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

    # install all NodeJS dependencies
    cd petanque\Petanque\petanquefrontend
    npm install

    # populate the database with the correct tables
    cd ..\..\manage-db
    copy mysql.cfg.example1 mysql.cfg
    .\restore.ps1 0-empty-db.sql mysql.cfg
    exit

-----------------
How to start the application?
-----------------

Just run "start.ps1" in PowerShell
or create a shortcut with following content:

    powershell.exe -ExecutionPolicy Bypass -File "C:\...\...\start.ps1"
    (fill in the correct path)

You can use "stop.ps1" to stop the dotnet-backend and the node.js services.
And "update.ps1" to get the latest changes/fixes from GitHub.com.
